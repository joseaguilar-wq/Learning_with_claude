# 📚 Sistemas RAG (Retrieval-Augmented Generation)

**Nivel:** Intermedio
**Total:** 19 agentes



Sistemas que consultan tus propios documentos (PDFs, Excel, Notion) para dar respuestas precisas sin alucinar.

### Casos de uso:
- Bases de conocimiento internas.
- Análisis de manuales técnicos.
- Q&A de documentos legales.
